# 🛡️ Путь SOC-аналитика (L1) | Blue Team Portfolio

Привет! Этот репозиторий — мой открытый журнал обучения и практической работы на первой линии мониторинга безопасности (SOC L1). Здесь я фиксирую разборы инцидентов, правила корреляции, плейбуки и скрипты автоматизации.

> ⚠️ **Дисклеймер:** Все кейсы, логи и сетевые индикаторы в этом репозитории взяты из открытых лабораторий (LetsDefend, TryHackMe, BTLO), домашнего стенда или полностью обезличены в соответствии с правилами конфиденциальности.

## 🗂️ Навигация по репозиторию

* 📁 **[01-Home-Lab](./01-Home-Lab)** — Схема и настройка домашней лаборатории (Wazuh/ELK, Sysmon, VirtualBox).
* 📁 **[02-Detection-Rules](./02-Detection-Rules)** — Правила детекта (Sigma, SPL, KQL).
* 📁 **[03-Incident-Writeups](./03-Incident-Writeups)** — Отчеты о расследовании инцидентов и триаже алертов.
* 📁 **[04-Scripts-Automation](./04-Scripts-Automation)** — Python и PowerShell скрипты для обогащения IoC и парсинга логов.
* 📁 **[05-Playbooks](./05-Playbooks)** — Пошаговые алгоритмы реагирования на типовые угрозы.
